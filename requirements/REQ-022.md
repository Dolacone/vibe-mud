# REQ-022 - Area UI

## 情境

> 地區主分頁需要集中顯示目前 Location 內可互動的世界內容。

## 行為

1. `地區` 必須顯示目前 Location 的可互動 gathering option。
2. `地區` 必須顯示目前 Location 的 Buildings、extensions 與後端回傳的可用操作。
3. `地區` 必須顯示目前 Location 的地面 Item 與 Resource，並保留既有 Pickup 與 Drop 規則。
4. `地區` 必須顯示後端回傳的 Building recipes，並允許玩家建立 Building。
5. `地區` 必須顯示目前 Location 的 Monster 總數，不得在戰鬥前顯示尚未抽選的 Monster 種類。
6. 後端回傳 `attack` 時，`地區` 必須提供主動攻擊 Monster 的操作。
7. 主動攻擊完成後，`地區` 必須顯示戰鬥過程、結果、掉落物與最新 Monster 總數。
