# REQ-012 - Compact table interface

## 情境

> 已登入頁面隨功能增加而過長。玩家難以快速找到 AP、Location、持有物與可用 Action。介面需要以表格降低垂直長度。

## 行為

1. 已登入頁面必須在頂部表格顯示玩家身分、目前 AP 與目前 Location。
2. Resources 與 Inventory 必須各自使用緊湊表格顯示。
3. Available Routes、Gather、Convert 與 Craft 必須各自使用緊湊表格顯示。
4. Available Building recipes 與目前 Location 的 Buildings 必須各自使用緊湊表格顯示。
5. 每個 Resource、Item、Route、Action、recipe 或 Building 必須占用對應表格的一列。
6. 每列必須並排顯示該項目的主要資訊與可用 Action。
7. Recipe 的成本、inputs 與 output 必須顯示在同一列，不得再以巢狀清單增加頁面長度。
8. 表格化後必須保留目前所有玩家資訊、遊戲狀態、Action 與 Action 結果。
9. 沒有資料或可用 Action 時，對應區段必須保留明確的空狀態。
10. 窄螢幕顯示表格時，頁面不得產生水平方向溢出。
11. 本次變更不得改變 API contract 或遊戲規則。
