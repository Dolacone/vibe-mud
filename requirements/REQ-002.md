# REQ-002 - 前端登入

## 情境

> 現在只有後端登入 API。使用者缺少部署在 Cloudflare 的登入介面，也無法透過前端向後端確認目前登入的應用程式使用者。

## 行為

1. 使用者必須能從部署在 Cloudflare Pages 的前端開始 Google 登入。
2. Google 登入成功後，使用者必須回到前端。
3. 前端必須向後端查詢目前登入的應用程式使用者，不得從前端狀態或 Google 回應自行推定身分。
4. 有效 session 存在時，前端必須顯示後端回傳的應用程式使用者 ID、顯示名稱與電子郵件。
5. 有效 session 不存在時，前端必須顯示未登入狀態與登入操作，不得顯示先前取得的使用者身分。
