# REQ-007 - Typed resources

## 情境

> 玩家目前只有單一 Resource balance，無法區分不同用途的 Resource。遊戲需要 8 種獨立 Resource，讓玩家看到每種 Resource 的 quantity。

## 行為

1. 遊戲必須定義 `Food`、`Wood`、`Stone`、`Metal`、`Fiber`、`Hide`、`Medicinal` 與 `Arcane` 這 8 種 Resource。
2. 系統必須為每位玩家分別保存每種 Resource 的 quantity，不能將多種 Resource 合併為單一 balance。
3. 玩家尚未取得某種 Resource 時，該 Resource 的 quantity 必須為 0。
4. 玩家必須能在前端看到全部 8 種 Resource 與各自的 quantity。
5. Resource quantity 必須保存為獨立於 Inventory item quantity 的持久化玩家狀態。
