# REQ-014 - 玩家攜帶重量

## 情境

> 玩家可以持有超過負重門檻的 Item 與 Resource，讓採集與物資調度不中斷。超過門檻的玩家不能移動，直到目前重量回到門檻內。

## 行為

1. 每位玩家的移動負重門檻為 1000 重量單位。
2. Wood Item 每單位重 100。Wood Resource 每單位重 1。Wood Component 每單位重 10。其他 Resource 每單位重 1。
3. 系統依玩家持有的每種 Item 與 Resource 數量及其單位重量，計算目前攜帶重量。系統不保存計算結果。
4. 前端顯示後端回傳的目前攜帶重量與移動負重門檻。超重時必須顯示不能移動。
5. Pickup、Gather、Craft 與 Convert 可以使玩家的目前重量超過 1000。
6. Drop 維持不消耗 AP，且不受目前重量限制。
7. 如果玩家的目前重量小於或等於 1000，Move 可以依既有規則執行。
8. 如果玩家的目前重量大於 1000，Move 必須原子失敗。玩家的位置與 AP 都維持不變。
9. 後端必須將重量計算與 Move 拒絕結果寫入標準輸出。紀錄必須包含玩家 ID、操作、結果、request ID 與計算值。
10. 本需求不增加 Item 耐久度、倉庫、裝備負重加成、載具、體積或批次 Convert。
11. 每種 Item 必須分別定義單位重量，不能依 Item 類別名稱推導重量。
12. Wood Essence T1 每單位重量必須為 1。
13. Sawmill Package T1 每單位重量必須為 10。
