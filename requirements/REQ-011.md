# REQ-011 - Building durability and repair

## 情境

> 完成的 Building 目前不會自然耗損。玩家需要看到 Building 的耐久狀態，並能共同投入 AP 與素材維修。

## 行為

### 耐久度

1. `Building Lv1` 完成時必須取得 7 天耐久時間。
2. Building 必須隨現實經過時間自然減少剩餘耐久時間。
3. 剩餘耐久時間大於 0 時，Building 必須顯示為 Active。
4. 玩家必須能看到 Building 的耐久狀態與剩餘耐久時間。

### 停用與消失

5. 剩餘耐久時間到達 0 時，Building 必須顯示為 Disabled。
6. Disabled Building 必須保留 7 天，期間仍能維修。
7. Building 停用超過 7 天後必須永久消失。
8. 永久消失的 Building 不得再顯示或維修。
9. Building 永久消失後，不得繼續占用玩家在該 Location 的 Building 名額。

### 維修

10. 同一 Location 的所有玩家都能維修完成的 Building。
11. Building 的 owner 或權限設定不能阻止其他玩家維修。
12. 每次維修必須消耗維修玩家的 10 AP 與 1 Wood Resource。
13. 每次維修最多增加 1 小時耐久時間。
14. Active Building 必須從現有剩餘耐久時間增加 1 小時。
15. Disabled Building 必須從維修當下重新取得 1 小時耐久時間。
16. 維修後的耐久時間不能超過維修當下起算的 7 天。
17. 距離 7 天上限不足 1 小時時，維修必須扣除完整成本，並只增加至上限。
18. 維修玩家不在 Building 的 Location 時，維修必須失敗。
19. AP 或 Wood Resource 不足時，維修必須失敗。
20. 維修成功時，AP、Wood Resource 與 Building 耐久時間必須原子更新。
21. 維修失敗時，AP、Wood Resource 與 Building 耐久時間必須保持不變。
22. 前端只能顯示後端依 REQ-018 回傳的維修 Action，並在維修成功後顯示最新狀態。
23. Disabled Building 不得安裝 extension、增加 extension 施工 progress 或提供 extension 功能。
24. Building 維修並恢復 Active 後，原有 extension 必須恢復施工或使用，不需要重新安裝。
25. Building 永久消失時，其 extension 必須一併永久消失。
26. 合法的 extension 使用使 Building 剩餘耐久低於 0 時，本次使用必須成功，剩餘耐久必須設為 0，Building 隨後必須成為 Disabled。
27. Extension 的功能結果與 Building 耐久變化必須原子更新。
