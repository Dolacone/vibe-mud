# REQ-001 - 使用者 Google 登入

## 情境

> 使用者目前無法透過純 API 後端完成 Google 登入，也無法取得後端辨識出的應用程式身分。

## 行為

### API 邊界

1. 後端只提供 HTTP API，不產生遊戲前端或登入頁面。
2. Google 登入所需的導向回應不受純 JSON 回應限制。

### 登入

3. 使用者只能透過 Google SSO 登入，不提供本機密碼或其他身分提供者。
4. 使用者可以從未登入狀態開始 Google 登入，並在 Google 驗證成功後建立應用程式 session。
5. 後端必須驗證 Google 登入結果，驗證成功後才能建立 session。
6. Google 登入完成後，後端必須將使用者導向已設定的前端位置。
7. 同一個 Google 帳號重複登入時，系統必須辨識為同一個應用程式使用者。

### 身分回應

8. 已登入使用者可以透過 JSON 回應取得自己的應用程式使用者 ID、顯示名稱與電子郵件。
9. 沒有有效 session 的使用者必須收到 HTTP 401 JSON 回應。
10. 回應內容不能包含 Google authorization code、access token、refresh token、ID token、client secret 或 session secret。
