# REQ-019 - PWA standalone

## 情境

> 前端需要提供瀏覽器建立 PWA 捷徑與 standalone 視窗所需的公開 metadata。實際手機安裝、Google 登入與 standalone 顯示結果由玩家在部署後驗證。

## 行為

1. 前端 origin 必須公開提供 Web App Manifest，且瀏覽器可以讀取正確的 manifest content type。
2. Manifest 必須宣告 `Vibe MUD` 名稱、遊戲圖示、根啟動路徑、根 scope 與 `standalone` 顯示模式。
3. 前端入口文件必須公開提供 iOS home-screen 名稱、圖示、啟用 web app 與狀態列 metadata。
4. Production container 必須提供入口文件、Manifest 與 Manifest 宣告的全部圖示。
5. 玩家直接使用瀏覽器開啟根網址或前端路徑時，遊戲必須繼續作為一般網頁運作。
6. 此 MVP 不得註冊 Service Worker，也不提供離線遊戲、背景同步或推播通知。
7. 實際 iOS Safari 與 Android Chrome 的安裝、獨立視窗、Google 登入及遊戲操作不屬於自動驗收範圍。
