# REQ-017 - Sawmill T1

## 情境

> 玩家需要把 Wood Convert 取得的 Wood Essence T1 與 Wood Resource 製作成 Sawmill Package T1，安裝並完成 Sawmill T1，再以相同 30 AP 工作單位處理更多 Wood。

## 行為

1. `Sawmill Package T1` 必須具有後端定義的 Craft recipe。
2. Sawmill Package T1 recipe 必須消耗 30 AP、10 Wood Resource 與 1 個 Active Wood Essence T1，並產出 1 個 Sawmill Package T1。
3. Sawmill Package T1 recipe 不得使用其他 Resource 或其他 Essence。
4. `Sawmill T1` extension definition 必須使用 Sawmill Package T1，且施工需要 30 AP。
5. Completed Sawmill T1 必須提供 Sawmill Convert method。
6. Sawmill Convert method 必須消耗 30 AP，單次最多處理 6 個 Wood，每個 Wood 產出 1 Wood Resource，並各自具有 10% 機率產出 1 個 Wood Essence T1。
7. 玩家使用 Sawmill Convert method 時，必須指定提供該 method 的 Sawmill T1。
8. 每次 Sawmill Convert 成功時，必須減少所屬 Building 的 60 秒耐久時間。
9. 已安裝的 Sawmill T1 必須使用目前 definition 的 Convert capacity 與 Building 耐久消耗秒數，不得保存這兩個平衡值的歷史快照。
10. 前端必須顯示 `Sawmill T1` 與 `Sawmill Package T1`，不得使用稱號代替 tier。
11. 前端必須顯示後端依 REQ-018 回傳的 Sawmill Package T1 recipe 或 Sawmill Convert method，以及其成本、inputs、產出、capacity 與 Essence 機率。
12. Sawmill Convert 成功後，前端必須顯示最新 AP、Inventory、Resource、Essence 結果與 Building 耐久狀態。
